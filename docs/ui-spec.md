# 界面规范（复刻桌面版）

## 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏 48px：MICA ROM MANAGER · 游戏库 / 扫描导入 / AI刮削 / 设置 · 退出 │
├──────────┬───────────────────────────────────────────────────┤
│ 平台侧栏  │ 标题 + 统计（共 N 款 / 已选 M 款）      [操作按钮]   │
│ 200px    │ 筛选条：搜索 | 平台 | 状态 | 区域 | 语言 | 类型 | 标签 │
│          │        [收藏] [文件缺失] [清除筛选]                  │
│ 全部游戏  │ 工具行：全选 / 取消选择 / 批量编辑 / 移除 / 导出 CSV   │
│ NES  120 │ ┌───────────────────────────────────────────────┐ │
│ SNES  86 │ │ 表格：★ 封面 平台 标题 评分 区域 语言 特注 …    │ │
│ …        │ └───────────────────────────────────────────────┘ │
│          │ 分页：每页 50/100/200 · 首页/上一页/页码/下一页/末页   │
├──────────┴───────────────────────────────────────────────────┤
│ 状态栏 24px：数据目录 …                          Mica ROM Manager │
└──────────────────────────────────────────────────────────────┘
```

## 交互

| 操作 | 行为 |
| --- | --- |
| 双击行 | 打开编辑弹窗 |
| 右键行 | 上下文菜单：编辑 / 收藏 / AI 刮削 / 从库中移除 |
| 点星 | 直接改评分；再点同星取消（置 0），不触发行双击 |
| 行内下拉 | 平台 / 区域 / 语言 / 状态，改完立即落库并刷新当前页 |
| 复选框 | 多选；工具行显示已选数量，支持批量编辑/移除/导出 |
| 排序 | 点表头切换升/降序；排序字段白名单 |
| 筛选 | 写入 URL query（`q/platform/status/region/language/genre/tag/fav/missing/page/sort/desc`），刷新可恢复 |
| 删除 | 只移除记录，二次确认；ROM 文件不动 |
| 拖放 | 预留（后续支持拖入目录触发扫描） |

## 弹窗

- 编辑游戏：两列表单（标题占满、平台/类型、区域/语言、特注/年份、发行商/开发商、评分/状态、收藏、标签、备注、封面、只读信息）。
- 批量编辑：字段行 = 勾选 + 新值；只应用勾选字段。
- 确认：使用浏览器 `confirm`（`micaConfirm`），危险操作文案明确说明「文件不会被删除」。
- 反馈：底部居中 Toast 2.5s；错误 Toast 红色可点击关闭。

## 空状态

- 游戏库为空：「游戏库还是空的，先去『扫描 / 导入』添加一个库目录。」
- 筛选无结果：「没有符合条件的游戏，试试清除筛选。」
- 没有平台：「还没有平台数据，先在『扫描 / 导入』里添加库并扫描。」
- 未配置 AI：AI 刮削页顶部黄色提示，附「设置 → AI」链接。
